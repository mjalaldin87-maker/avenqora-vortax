## Practical test

1. Define the real workflow the tool must support.
2. Test representative examples, including difficult cases.
3. Record failures and manual workarounds.
4. Confirm which features require higher plans or separate services.
5. Review permissions and data handling before using sensitive information.
6. Record the evidence and date for important claims.
7. Decide whether the tool should be adopted, piloted, rejected, or reviewed again.
