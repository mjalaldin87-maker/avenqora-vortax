QR Code Phishing (Quishing): How Students Can Scan Safely

QR-code phishing, sometimes called quishing, uses a QR code to send someone to a deceptive website or harmful action. Students may see codes in emails, posters, parcels, social posts or event notices. This lesson explains how to check the destination before sharing information.

QR code phishing for students is a form of social engineering in which a QR code hides a web address or prompts a risky action. A code may look like an ordinary poster, payment notice, delivery message or sign-in link. The danger is not the square pattern itself; it is the destination and the request that follows.

How quishing works

A scammer creates a QR code that opens a fraudulent page or initiates another action. The page may imitate a school login, parcel service, bank, event registration or file-sharing platform. It may ask for a password, one-time code, payment details or personal information.

QR codes can be printed or shared digitally. A legitimate-looking location does not prove that the code is safe: a sticker may have been placed over a real code, or a code in an email may lead to a fake website.

Warning signs before and after scanning

  • A message urges you to scan immediately to avoid losing access, money or a delivery.
  • The code appears on a sticker that covers or changes an official poster.
  • The page address is misspelled, uses an unfamiliar domain or does not match the organisation.
  • The page asks for a password, one-time code or payment information that the message did not reasonably explain.
  • The page uses urgency, threats, prizes or unusual secrecy to stop you checking with someone.
  • The QR code was sent by an unknown person or through an unexpected attachment.

These signs do not prove that every code is malicious. They are reasons to pause and verify the source through a separate trusted route, such as the official website typed into your browser or a contact method already known to you.

Safer steps before you open a QR destination

  1. Check the source. Ask who placed or sent the code and whether you expected it.
  2. Inspect the physical code. Look for stickers, damage or a code that appears to cover another one.
  3. Use your phone's built-in scanner. Avoid downloading an unfamiliar QR scanner app solely because a message tells you to.
  4. Preview the destination. Read the displayed domain carefully before opening it.
  5. Verify independently. For a school, bank or parcel message, use the organisation's known website or phone number rather than the code.
  6. Stop if the request feels wrong. Do not enter passwords, payment data or one-time codes on a page you cannot verify.

What to do if you opened a suspicious page

If you opened a page but did not enter information, close it and do not download files or approve notifications. If you entered a password, change it using the real service's official site, enable or review MFA and tell a trusted adult or school IT contact. If you shared payment details, contact the payment provider promptly.

If you entered a one-time code or approved a sign-in prompt, contact the account provider through its official support route. Review active sessions and recovery details. Do not respond to follow-up callers who claim they can fix the issue but ask for another code or payment.

School and event QR-code safety

Schools, clubs and event organisers can reduce confusion by publishing the destination in plain text beside the QR code, using a consistent official domain, checking posters after they are displayed and providing a non-QR way to reach the same information. Students should be able to ask a teacher or organiser to verify an unfamiliar code.

When a code is used for attendance, payments or sign-in, check that the collection process explains what information is requested and who receives it. Do not assume that a QR code is safe simply because it appears on a school noticeboard or event poster.

Quick classroom practice

Look at a sample QR-code poster supplied by a teacher. Identify the organisation, visible domain, requested information and an independent way to verify it. Do not scan unknown live codes during the exercise. Discuss which details make the message trustworthy and which details need confirmation.

Frequently asked questions

What is quishing?

Quishing is QR-code phishing. It uses a QR code to send a person to a deceptive website or another unsafe action. The code hides the destination from plain view, so the user should inspect the displayed domain and verify the source before entering information.

Are all QR codes dangerous?

No. QR codes are a convenient way to share links and information. The risk comes from a code that leads to a deceptive or harmful destination, or from a code that has been replaced. Check where it came from and preview the destination before proceeding.

What should I do if a QR code asks for my school password?

Stop and verify the request through the school's official website or a teacher using a known contact method. Do not enter your password or one-time code on an unexpected page. If you already shared it, change the password through the real school sign-in page and report the incident.

Can a QR code install malware automatically?

Scanning a code normally opens or offers a destination; it does not mean malware has automatically been installed. Risk increases if you download a file, install an app, grant permissions or follow deceptive instructions. Close suspicious pages and do not approve unexpected downloads or prompts.

What if I scanned a fake QR code at school?

Tell a teacher, parent or school IT contact, especially if you entered account details or payment information. Save the poster or message details if safe, but do not share the suspicious link with other students as a warning. Ask the school to verify and report the code.

Key takeaway

Pause before opening an unfamiliar QR destination. Check who provided the code, preview the domain, verify unexpected requests independently and never share passwords or one-time codes on an untrusted page. If you make a mistake, report it quickly and secure the affected account.
