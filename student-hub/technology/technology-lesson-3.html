What is an API?

API stands for Application Programming Interface. An API is a defined way for one software system to communicate with another. Instead of knowing how another application works internally, a program can use the interface it exposes.

What is a request?

A request is a message sent to an API asking for information or an action. A request can contain a method, a URL, headers and data. For example, a weather application may request current weather information for a particular city.

What is a response?

The receiving service sends a response. A successful response may contain requested data. An unsuccessful response may contain an error and a status code explaining what happened.

Simple model

Application → API request → Service → API response → Application

Common API methods

  • GET — retrieve information
  • POST — send or create information
  • PUT or PATCH — update information
  • DELETE — remove information

Where are APIs used?

APIs are used in payment systems, maps, social platforms, cloud services, authentication, analytics, e-commerce and many other digital products. When a mobile application displays information stored on a remote server, an API may be part of the communication process.

Why does authentication matter?

Some APIs provide public information while others contain private or valuable data. Authentication helps a service identify the caller. Authorization then determines what that caller is allowed to do.

What should students remember?

An API is not simply a database. It is an interface and set of rules for communication. Learning how requests and responses work gives students a useful foundation for web development, mobile development, cloud computing and SaaS.

Quick review

  • API means Application Programming Interface.
  • A request asks a service for data or an action.
  • A response returns data or an error.
  • Authentication helps identify a caller.
  • Authorization controls permissions.
