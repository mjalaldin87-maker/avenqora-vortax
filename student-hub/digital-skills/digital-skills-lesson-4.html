Spreadsheet Skills: Formulas, Sorting and Charts

Spreadsheets help organize information, perform calculations and make patterns easier to see. This lesson introduces cells, formulas, sorting, filters and charts through a simple example.

Prepared by Zia CarterNovember 5, 2026Beginner lesson
Back to Digital Skills lessons

What you will learn

  • Identify workbooks, worksheets, cells and ranges
  • Use basic formulas and functions
  • Sort, filter and visualize a small dataset responsibly

What is a spreadsheet?

A spreadsheet is a digital grid used to organize information and calculate results. A workbook may contain several worksheets. Each worksheet is arranged in rows and columns. A cell is where a row and column meet, and a cell address such as B3 identifies its location.

A range is a group of cells. For example, B2:B6 refers to cells B2 through B6. Understanding ranges helps you write formulas that work with several values at once.

Enter data in a consistent structure

Use one row for each record and one column for each field. A student budget sheet might use columns for date, category, description and amount. Keep one clear header row. Avoid merging cells inside the data table because it can make sorting and filtering harder.

Choose suitable formats for dates, numbers and currency. A value that looks like a number but is stored as text may not calculate as expected.

Formulas and functions

A formula begins with an equals sign. It can use cell references, operators and functions. For example, =B2+C2 adds the values in two cells. A function is a named operation that performs a calculation.

=SUM(D2:D6)
=AVERAGE(D2:D6)
=IF(D2>=500,"Review","Within plan")

The first example totals a range. The second calculates an average. The third checks a condition and returns one of two results. Function names and supported syntax can differ slightly between spreadsheet products, so use the help for the tool you are using.

Understand cell references

When a formula is copied to another cell, relative references normally adjust to the new position. Absolute references use dollar signs, such as $B$1, to keep a reference fixed when the formula is copied. This is useful when many rows use the same tax rate or exchange rate stored in one cell.

Sort and filter carefully

Sorting rearranges records based on a selected column. Filtering temporarily hides rows that do not meet a condition. Always select the full table when sorting. Sorting only one column can disconnect values from their original records.

Before changing a shared sheet, make a copy or confirm that the owner expects the data to be changed. Use filters to explore a dataset without deleting rows that may be useful to someone else.

Choose a chart that answers a question

A chart should make a comparison or pattern easier to understand. A column chart can compare categories, a line chart can show change over time and a pie chart can show parts of a whole when there are only a few meaningful categories. Add a clear title, label units and do not use color alone to communicate important differences.

Worked example: monthly student spending

Imagine a student records transport, meals, books and mobile data costs for one month. The amount column can be totaled with =SUM(D2:D5). A category column can be used to filter only transport costs. A column chart can compare the four categories. The student can then ask which category changed most and whether the records include every purchase.

Practice task

  1. Create a sheet with five expense records and columns for date, category and amount.
  2. Use SUM to calculate the total amount.
  3. Use AVERAGE to calculate the average expense.
  4. Sort the full table by amount from largest to smallest.
  5. Create a chart that compares spending by category.

Accuracy and privacy checks

Check formulas against a manual calculation for a small sample. Look for blank cells, repeated records and inconsistent categories. Do not place passwords or highly sensitive personal information in a shared spreadsheet. Review sharing permissions before sending a link.

Quick review

  • A cell is identified by a column letter and row number.
  • Formulas begin with an equals sign.
  • Functions perform reusable calculations.
  • Sort the whole dataset so records remain together.
  • Charts should answer a clear question and label their data.
