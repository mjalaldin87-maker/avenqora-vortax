# Weekly SEO & Authority Tracking

Run this check once per week, preferably Friday, and compare trends rather than reacting to one day's movement.

## Friday checklist

- [ ] Check Google Search Console indexing and coverage.
- [ ] Check Search Console impressions and clicks.
- [ ] Check indexed pages against the site's intended indexable pages.
- [ ] Check Semrush Authority Score and referring domains.
- [ ] Review new backlinks and investigate suspicious or irrelevant domains.
- [ ] Check important keyword movements.
- [ ] Test a sample of internal links and key pages.
- [ ] Run PageSpeed Insights on representative mobile pages.
- [ ] Record changes and actions for the next week.

## What each number means

**Authority Score:** A third-party Semrush estimate of a domain's authority. It is not a Google ranking score.

**Referring domains:** Distinct domains that link to the site. One domain can produce multiple backlinks.

**Backlinks:** Individual discovered links. A high number is not automatically good; relevance and quality matter.

**Organic keywords:** Search terms for which an SEO tool estimates the site has visibility. Estimates differ between tools and Google.

**GSC impressions:** How often a site's result was shown in Google Search for tracked queries.

**GSC clicks:** Clicks from Google Search to the site.

**Indexed pages:** Pages Google has actually included in its index; this may differ from the number submitted in a sitemap.

**PageSpeed mobile:** A performance measurement for the tested page and conditions. Check representative pages rather than assuming one URL represents the whole site.

## Realistic expectations

A new site can take time to accumulate crawl history, indexed pages, impressions, links, and stable keyword visibility. The first 1–3 months can be slow and uneven. Do not buy links, manufacture reviews, or make large changes solely because a weekly metric moved down.

Focus on publishing useful material, maintaining technical accessibility, earning legitimate mentions, improving internal linking, and resolving real Search Console issues.
