# White-Hat Outreach Playbook

## Legitimate site/community types

| Type | What to offer |
|---|---|
| Industry publication | Original expert article with evidence and useful examples |
| SaaS publication | Practical workflow, implementation guide, or case study |
| Cybersecurity publication | Defensive guide, checklist, or educational analysis |
| Small-business publication | Actionable operations or marketing guide |
| Developer publication | Tutorial with original implementation details |
| University student publication | Educational explainer or career resource |
| Professional association | Educational contribution relevant to members |
| Local business association | Practical digital-business guide |
| Chamber of commerce | Small-business technology resource |
| Startup community | Founder/operator playbook |
| Open-source community | Documentation improvement or technical guide |
| Developer newsletter | Concise technical tutorial |
| Security newsletter | Defensive checklist or analysis |
| Business newsletter | Practical B2B operations article |
| Industry conference blog | Educational recap or technical explainer |
| Vendor-neutral resource site | Research-backed educational content |
| Podcast show notes site | Useful supporting resource where permitted |
| Community knowledge base | Documentation or FAQ contribution |
| Scholarship/student resource site | Original student learning material |
| Career resource site | Honest career-learning guide |
| Professional forum | Helpful answer where links are allowed |
| Relevant Q&A community | Complete answer first; optional resource link |
| Niche blog | Original article matched to its audience |
| Digital marketing publication | Evidence-based SEO/content article |
| Entrepreneurship publication | Practical small-business guide |

Do not pay for links merely to manipulate rankings. Do not use private blog networks, link exchanges, fake accounts, spam comments, fake reviews, or misleading identities.

## Weekly outreach routine

**Monday:** research new prospects and remove duplicates.

**Tuesday:** verify site relevance, public contact details, editorial rules, and whether the opportunity is direct or agency-managed.

**Wednesday:** send a small batch of personalized inquiries.

**Thursday:** follow up with the appropriate prospects; do not repeatedly contact the same team.

**Friday:** update outcomes, remove dead opportunities, record negotiated terms, and review which site types produce useful placements.

## Link-type reality

Quora, Reddit, Medium, LinkedIn and similar platforms commonly use nofollow, sponsored, or otherwise non-editorial link attributes depending on the platform and placement. Their value can still include referral traffic, visibility, relationships, and discovery. A referring domain can also appear in SEO tools without meaning that the link is followed or that it directly transfers ranking value. Do not promise a specific ranking effect from any single link.

Semrush Authority Score is a third-party metric. More referring domains can be useful, but quality, relevance, editorial legitimacy, and the actual value of the referring site matter more than chasing a raw count.
